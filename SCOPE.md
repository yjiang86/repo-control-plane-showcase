# Export scope

Included source: `tools/leasectl`, `tools/devcheckpointctl`, `tools/frozenpatch.py`, their package markers, three original synthetic contract-test modules, and the dynamic coordination-lock JSON schema. The tests also require `tools/adoptctl/{__init__,core}.py` and `tools/topctl/{__init__,cli}.py`; these four dependency files are included without advertising additional supported command entrypoints. Source is selected from release `v0.1.0-dev.174`; private export evidence records exact source blobs and output hashes. Ten occurrences of one synthetic fixture prefix were generalized without changing test conditions.

Included supporting material: this export's README, architecture and case descriptions, packaging metadata, runnable synthetic example, and actual sample-verification summary.

Excluded: all original Git history and refs; repository and workstation inventories; real account identities and authentication material; research subjects and data; private review packages and recovery logs; raw conversations and owner messages; institution or cluster topology; deployment scripts and host configuration; screenshots; third-party datasets and binaries. Runtime test logs and the private export audit remain outside the delivery repository.

The sample is a source-code demonstration. The broader project's delivery, installation, actual runtime, and scientific acceptance remain separate claims.
